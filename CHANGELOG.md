# Изменения

## Вид с категориями по умолчанию, 12.10.2026

* Пустой параметр виджета теперь открывает категории. `OVERVIEW` по-прежнему включает общий обзор.
* «Еда» закреплена отдельной строкой, даже если её сумма равна нулю или меньше других категорий. Затем показаны две крупнейшие другие категории, последняя строка «Прочее» объединяет оставшиеся.
* Группировка сохраняет общий итог, включая возвраты.
* Добавлены три проверки режима и отображения. Всего 23 группы проверок.

## 12.10.2026, вечер

* QuickActions: у кнопки появилось необязательное поле прямой ссылки (Notion, Maps, Slack). Если оно заполнено, кнопка открывает приложение сразу, минуя «Команды». Пустое поле — запуск команды, как раньше.
* SpendWidget: пустой запуск автоматизации не создаёт запись в журнале.
* SpendWidget: карта категорий магазинов пишется атомарно; битый файл сохраняется копией, а не затирается.
* SpendWidget: Octopus распознаёт магазины с цифрами в названии (7-Eleven).
* Проверки: 20 групп.

## Публичная копия, 12.10.2026

* SpendWidget: за основу взят последний полный код v1.5 из беседы.
* Встроенный пример уведомления заменён полностью вымышленными суммой и остатком.
* Исправлена проверка обрезанного названия Mox: `Cafe...` отправляется на проверку. Раньше удаление конечных точек происходило до проверки многоточия, поэтому операция могла считаться расходом.
* QuickActions: взята последняя версия QuickActions Fixed, сетка 3 × 2, кнопки 104 × 61, подписи рисуются по центру всей ширины кнопки. Все шесть имён команд сохранены.
* Добавлены инструкция установки, настройка команд, ограничения и 17 групп проверок с вымышленными данными.
