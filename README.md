# iPhone Scriptable Widgets

Три средних виджета для iPhone: SpendWidget v1.5 для расходов, QuickActions для запуска шести команд и MyDayWidget v4 с погодой и планом встреч. Исходники восстановлены из последней полной версии каждого скрипта в истории разработки.

## Установка в Scriptable

1. Установи [Scriptable](https://scriptable.app/) и открой приложение «Команды» (Shortcuts).
2. Открой [SpendWidget.js](SpendWidget/SpendWidget.js), нажми **Raw**, скопируй весь код. В Scriptable создай скрипт с именем `SpendWidget` и вставь код.
3. Так же установи [QuickActions.js](QuickActions/QuickActions.js) под именем `QuickActions`. Это последняя версия **QuickActions Fixed** с широкими кнопками и центрированными подписями. Если используешь прежнее имя `QuickActions Fixed`, можешь оставить его.
4. Запусти каждый скрипт кнопкой ▶. SpendWidget откроет меню, QuickActions покажет предпросмотр.
5. На домашнем экране добавь **средний** виджет Scriptable. Через «Изменить виджет» выбери нужный скрипт. **SpendWidget теперь показывает категории по умолчанию:** Parameter оставь пустым или укажи `CATEGORIES`. Строки «Еда» и «Прочее» видны всегда. Для общего обзора укажи `OVERVIEW`. Если этот параметр уже стоял в старом виджете, замени его на `CATEGORIES`. Можно добавить оба вида: они используют одну историю расходов. Для QuickActions параметр не нужен.

Предпросмотр в Scriptable показывает текущий код. Обновление изображения на домашнем экране зависит от iOS и может произойти позже. Размеры кнопок QuickActions рассчитаны на средний виджет; на конкретном iPhone нужно проверить, что края не обрезаются.

## Обновление одной кнопкой

Один раз вставь [Updater.js](Updater/Updater.js) в Scriptable под именем `Updater` и запусти. Он скачает свежие SpendWidget, QuickActions и MyDayWidget из этого репозитория и запишет поверх старых (если скрипт называется `QuickActions Fixed`, обновит его). Перед записью проверяет синтаксис и кладёт рядом копию `.bak`. Историю расходов не трогает. Дальше любое обновление — просто запуск `Updater`.

## Виджет «Команд» без открытия приложений

Виджет Scriptable по тапу всегда сначала открывает Scriptable. Родной виджет «Команд» запускает команду в фоне: VPN и таймер срабатывают без открытия приложений, окна ввода «Идеи» и «Slack себе» появляются поверх экрана «Домой». Команды менять не нужно.

1. В «Командах» создай папку `Виджет` и перенеси туда `QA VPN`, `QA Timer`, `QA Idea`, `QA Slack`.
2. На экране «Домой» добавь средний виджет «Команды», в настройках выбери папку `Виджет`.

## MyDayWidget v4: план дня

[MyDayWidget.js](MyDayWidget/MyDayWidget.js) показывает погоду на сегодня и до трёх ближайших встреч выбранного календаря. Если сегодняшние встречи закончились или их нет, показывает ближайший день с встречами в пределах следующих семи дней. Исключает события на весь день, отпуска, праздники, Out of Office и отменённые встречи. Цветные полоски берёт из календаря. Нажатие открывает системный календарь.

1. Обнови `Updater` из [актуального файла](Updater/Updater.js) и запусти его. Он добавит `MyDayWidget`, либо обновит существующий `MyDayWidget-v4`. Можно также вручную скопировать код в Scriptable.
2. Добавь средний виджет Scriptable и выбери `MyDayWidget` (или прежнее имя `MyDayWidget-v4`).
3. В **Parameter** укажи точное название своего рабочего календаря, как оно отображается в приложении «Календарь». Личный адрес в публичный код не включён. Параметр виджета сохраняется при обновлении кода.
4. Чтобы проверить скрипт кнопкой ▶ внутри Scriptable, локально впиши имя календаря в пустую строку `args.widgetParameter || ''`. В публичную копию эту настройку не загружай. Для автоматизации Shortcuts имя календаря тоже нужно задать локально: она не получает Parameter домашнего виджета.
5. Разреши Scriptable доступ к календарям и геолокации. Google Calendar должен быть подключён к календарям iOS. Если доступа нет или название не совпало, виджет покажет сообщение об ошибке.

Погода запрашивается у Open-Meteo с координатами, полученными через геолокацию. Названия встреч и содержимое календаря туда не отправляются. Погода кешируется в `myday-weather-cache.json` на 45 минут; при ошибке используется доступный кеш. Обновление виджета запрашивается раз в 15 минут, фактическое время выбирает iOS.

Это версия v4 из истории беседы с заменой зашитого адреса календаря на настройку. Проверены синтаксис и сценарии с вымышленными событиями. Отображение и разрешения на настоящем iPhone нужно проверить.

```sh
node tests/verify-myday.cjs
```

## BodyWidget: сон, шаги, пульс покоя

Данные браслета Google (Fitbit) попадают в Apple Health через Google Health → Connections → Apps and services → Apple Health. Scriptable не читает Apple Health сам, поэтому их передаёт команда.

Команда «Тело: обновить»:

1. «Найти образцы Здоровья»: Тип — Шаги, Дата начала — сегодня, Группировать — по дням.
2. «Найти образцы Здоровья»: Тип — Анализ сна, Дата начала — за последние 1 день, Значение — Сон (Asleep).
3. «Получить сведения об образце Здоровья»: Длительность (из шага 2).
4. «Вычислить статистику»: Сумма (из шага 3).
5. «Найти образцы Здоровья»: Тип — Пульс в покое, сортировка — Дата начала, от новых, ограничение — 1.
6. «Словарь»: `steps` — результат шага 1, `sleepMin` — результат шага 4, `restingHR` — результат шага 5.
7. «Run Script» (Scriptable) → BodyWidget, Parameter — словарь. Show When Run выключи.

Автоматизации «Время суток» в 8:00, 13:00 и 21:00 запускают эту команду. Виджет — средний Scriptable → BodyWidget. Тап открывает Google Health. Цели шагов и сна — в меню скрипта. HRV Google Health в Apple Health пока не передаёт.

## SpendWidget CN (юани, только Alipay)

`SpendWidget/SpendWidget-CN.js` — готовая версия для телефона, где платят только Alipay: итоги в CNY, Alipay считается расходом, WeChat игнорируется. Понимает уведомления «交易提醒 你有一笔 X 元的支出» (рекламный «领2元红包» не считается), «退款提醒» отправляет на проверку. Автоматизация: Notification → приложение Alipay → Run Script → SpendWidget, Parameter = Shortcut Input, Show When Run выключен.

## SpendWidget для расходов в юанях (Alipay / WeChat Pay)

С версии 1.7 в меню SpendWidget есть «Настройки: валюта и Alipay/WeChat». Для телефона, где основные траты в Китае:

1. Поставь Scriptable, импортируй Updater (файл `Updater.scriptable`) и запусти его. Он установит SpendWidget.
2. Открой SpendWidget → «Настройки» → валюта **CNY**, Alipay **Считать расходом**, WeChat Pay **Считать расходом**.
3. В «Командах» создай две автоматизации «Уведомление» (iOS 27): от приложения Alipay и от WeChat. Действие одно: Run Script → SpendWidget, Parameter — словарь `source` = `Alipay` (или `WeChat`), `title` и `message` из уведомления. Включи «Запускать сразу».
4. Для Octopus в Гонконге — третья автоматизация с `source` = `Octopus`.
5. Добавь средний виджет Scriptable → SpendWidget.

Входящие переводы, возвраты, пополнения и остаток («余额») расходом не считаются. Если в тексте нет магазина, операция записывается как «Alipay» / «WeChat», категорию можно назначить через «Разобрать без категории». Форматы уведомлений Alipay и WeChat разбираются по типовым шаблонам; проверь на реальных через «Тест уведомления».

Настройки хранятся в папке данных и не меняются при обновлении скрипта. По умолчанию всё как раньше: HKD, Alipay исключён, WeChat на проверку.

## Октопус и PayMe (с версии 1.8)

Проезд по Octopus не даёт уведомлений, поэтому его ловит автоматизация «Транзакция» из Wallet:

1. «Команды» → «Автоматизация» → «+» → «Транзакция» → карта Octopus → «Запускать сразу».
2. Действие «Словарь»: `amount` — Сумма, `merchant` — Продавец, `card` — Карта (переменные из «Входа ярлыка»).
3. «Run Script» → SpendWidget, Parameter — словарь.

Карты Mox в триггер не добавляй: они уже учитываются по уведомлениям, будут дубли.

PayMe: автоматизация «Уведомление» от приложения PayMe, словарь `source` = `PayMe`, `message` — текст уведомления. Оплата магазину («You paid HK$… to …») идёт в расходы, переводы людям и поступления — на проверку.

## SpendWidget v1.5

По умолчанию показывает категории за месяц в HKD: «Еда», две крупнейшие другие категории и «Прочее» (сумма остальных категорий). «Еда» остаётся отдельной строкой даже при нулевых расходах. В режиме `OVERVIEW` показывает расходы за сегодня, последние семь дней и месяц. Категории: Еда, Транспорт, Поездки, Здоровье, Покупки, Услуги и Без категории. Магазину можно назначить категорию через **Журнал / исправления → операция → Запомнить категорию магазина**. Назначение действует на прошлые и будущие операции с таким названием.

| Источник | Что делает скрипт |
|---|---|
| Mox | Разбирает `You spent <валюта> <сумма> at <магазин>` |
| Octopus | Разбирает `HK$<сумма> for Train` и другие поддержанные назначения; остаток не учитывает |
| SC / Standard Chartered | Сохраняет для ручной проверки |
| Alipay | Исключает, предполагая учёт той же покупки через Mox |
| Неизвестный источник | Сохраняет для ручной проверки |

Пополнения Octopus, отмены, банковские возвраты и непонятные форматы требуют проверки. Возврат можно добавить вручную. Код скрывает распознанные одноразовые коды подтверждения из сохраняемого текста.

Одинаковые расходы из уведомлений одного источника с той же суммой, валютой и магазином в пределах 120 секунд попадают на проверку и не увеличивают итог до подтверждения. Это эвристика; две настоящие покупки тоже могут совпасть. Между разными источниками универсальной защиты нет. Не подключай одновременно Wallet и банк для одной покупки. Исключение Alipay подходит только при оплате через учитываемый банк; расходы с отдельного баланса Alipay эта конфигурация пропустит.

Курсы берутся из Frankfurter и кешируются на сутки. Итоги в HKD оценочные, пересчитываются по доступному курсу; это не банковская выписка. Звёздочка обозначает потенциально неполные данные.

### Передача данных из Shortcuts

Scriptable получает данные через параметр действия **Run Script**, а не читает уведомления самостоятельно. [Документация Scriptable](https://docs.scriptable.app/args/) описывает `shortcutParameter`.

Для проверки создай команду:

1. Добавь **Dictionary** с полями `source` = `Octopus` и `message` = `HK$10.00 for Train`.
2. Добавь действие **Run Script** от Scriptable, выбери `SpendWidget`, передай словарь в Parameter. Не включай Show When Run, если нужен запуск без меню.
3. Добавь **Show Result** для результата скрипта. Ожидаемый ответ: `Записано: 10 HKD · Train`. Этот запуск сохраняет тестовый расход. После проверки исключи его через журнал.

Принимается также текст, где первая строка содержит источник:

```text
Mox
You spent HKD 25.50 at Example Cafe
```

Для проверки без сохранения используй встроенное меню **Тест уведомления**. Вымышленный пример Octopus должен дать `10 HKD`, `Train`, категорию `Транспорт`.

На iOS 27 есть триггер уведомления от выбранного приложения: [Apple, WWDC26](https://developer.apple.com/videos/play/wwdc2026/310/). Создай автоматизацию получения уведомления Mox или Octopus и передай имя приложения в `source`, а доступные заголовок и текст в `title` и `message`. При необходимости получи эти свойства из входного уведомления перед созданием словаря. Меню и доступность полей зависят от версии iOS; сначала проверь передачу вымышленного текста обычной командой. [Инструкция Apple по автоматизациям](https://support.apple.com/en-euro/guide/shortcuts/apdfbdbd7123/10.0/ios/27).

Если триггера уведомления в твоей версии iOS нет, используй ручной ввод, копирование текста в команду или передачу текста через меню «Поделиться». Триггер Apple Pay Transaction сам по себе не подходит: парсер ждёт поддержанный текст Mox/Octopus, а не произвольный объект транзакции.

### Данные и обновление

История хранится локально через `FileManager.local()` в `SpendWidget-data-v1`. В ней остаются суммы, магазины и исходные тексты уведомлений. Экспорт JSON содержит эти данные.

Перед обновлением сохрани старый код и экспорт истории в личном месте. Затем замени только код скрипта, оставив имя `SpendWidget`. Папку `SpendWidget-data-v1` не удаляй. Поддерживается прежняя история с форматом событий `schema: 1`; импорт произвольных старых форматов не реализован.

## QuickActions и шесть команд

Создай команды с точными именами из таблицы. Виджет запускает их через [URL-схему Shortcuts](https://support.apple.com/en-euro/guide/shortcuts/apd624386f42/ios); переход в приложение «Команды» возможен.

| Кнопка | Имя команды | Настройка |
|---|---|---|
| Happ VPN | `QA VPN` | Set VPN → выбери свой профиль Happ → Connect или Toggle |
| Идея | `QA Idea` | Ask for Input → Copy to Clipboard → URL своей страницы Notion → Open URLs |
| TrainChinese | `QA Translate` | Open App → TrainChinese |
| Таймер | `QA Timer` | Choose from Menu: 1 час / 3 часа → Start Timer на 3600 / 10800 секунд |
| Домой | `QA Home` | Маршрут от текущего местоположения до своего адреса; выбери Google Maps или Apple Maps и способ передвижения |
| Slack себе | `QA Slack` | Ask for Input → Copy to Clipboard → Open App → Slack; вставь текст и отправь в DM себе |

Для `QA Idea` укажи подсказку «Какая идея?», в Copy to Clipboard передай Provided Input. Ссылку страницы возьми в Notion через Share → Copy link. После открытия вставь текст самостоятельно; автоматическое создание записи через Notion API здесь не настроено.

Для `QA Slack` используй подсказку «Что отправить себе?». Если твоя версия Slack предоставляет собственное действие отправки сообщения в Shortcuts, можешь заменить копирование и открытие приложения этим действием, указав свой DM и Provided Input. Наличие такого действия здесь не подтверждено. Для отправки через Slack API потребуется отдельная личная настройка авторизации; токены в виджет не добавлены.

Домашний адрес, ссылку Notion и получателя Slack настрой только на своём телефоне. В репозитории их нет. Сначала проверь каждую команду кнопкой ▶ в Shortcuts, затем через виджет.

## Проверка исходников

Проверены синтаксис обоих скриптов и 23 группы проверок: Mox/Octopus, категории, суммы и даты, исключения, скрытие OTP, дубли, сохранение и правки, курсы и возвраты, шесть кнопок QuickActions и ссылки. Отдельно проверены режим по умолчанию, постоянное отображение «Еда» и «Прочее» и сохранение общей суммы при группировке. Проверки используют имитацию API Scriptable и вымышленные данные. На реальном iPhone запуск, отображение, автоматизации и команды приложений ещё нужно проверить.

```sh
node tests/verify.cjs
```

Для публичной копии заменён пример реального уведомления на вымышленный и исправлена проверка обрезанного названия магазина. Подробности в [CHANGELOG.md](CHANGELOG.md).

## Что не публиковать

В репозитории только код, инструкции и проверки. Не добавляй историю расходов, экспорт, личные настройки команд, снимки уведомлений, адреса, номера карт, Slack/Notion/VPN-токены. `.gitignore` исключает типичные файлы с такими данными, но перед публикацией своих изменений проверяй содержимое вручную.
