# iPhone Scriptable Widgets

Два средних виджета для iPhone: SpendWidget v1.5 для расходов и QuickActions для запуска шести команд. Исходники восстановлены из последней полной версии каждого скрипта в истории разработки.

## Установка в Scriptable

1. Установи [Scriptable](https://scriptable.app/) и открой приложение «Команды» (Shortcuts).
2. Открой [SpendWidget.js](SpendWidget/SpendWidget.js), нажми **Raw**, скопируй весь код. В Scriptable создай скрипт с именем `SpendWidget` и вставь код.
3. Так же установи [QuickActions.js](QuickActions/QuickActions.js) под именем `QuickActions`. Это последняя версия **QuickActions Fixed** с широкими кнопками и центрированными подписями. Если используешь прежнее имя `QuickActions Fixed`, можешь оставить его.
4. Запусти каждый скрипт кнопкой ▶. SpendWidget откроет меню, QuickActions покажет предпросмотр.
5. На домашнем экране добавь **средний** виджет Scriptable. Через «Изменить виджет» выбери нужный скрипт. Для SpendWidget поставь Parameter `OVERVIEW` или `CATEGORIES`. Можно добавить оба вида: они используют одну историю расходов. Для QuickActions параметр не нужен.

Предпросмотр в Scriptable показывает текущий код. Обновление изображения на домашнем экране зависит от iOS и может произойти позже. Размеры кнопок QuickActions рассчитаны на средний виджет; на конкретном iPhone нужно проверить, что края не обрезаются.

## SpendWidget v1.5

Показывает расходы за сегодня, последние семь дней и месяц в HKD, либо категории за месяц. Категории: Еда, Транспорт, Поездки, Здоровье, Покупки, Услуги и Без категории. Магазину можно назначить категорию через **Журнал / исправления → операция → Запомнить категорию магазина**. Назначение действует на прошлые и будущие операции с таким названием.

| Источник | Что делает скрипт |
|---|---|
| Mox | Разбирает `You spent <валюта> <сумма> at <магазин>` |
| Octopus | Разбирает `HK$<сумма> for Train` и другие поддержанные назначения; остаток не учитывает |
| SC / Standard Chartered | Сохраняет для ручной проверки |
| Alipay | Исключает, предполагая учёт той же покупки через Mox |
| Неизвестный источник | Сохраняет для ручной проверки |

Пополнения Octopus, отмены, банковские возвраты и непонятные форматы требуют проверки. Возврат можно добавить вручную. Код скрывает распознанные одноразовые коды подтверждения из сохраняемого текста.

Одинаковые расходы из уведомлений одного источника с той же суммой, валютой и магазином в пределах 120 секунд попадают на проверку и не увеличивают итог до подтверждения. Это эвристика; две настоящие покупки тоже могут совпасть. Между разными источниками универсальной защиты нет. Не подключай одновременно Wallet и банк для одной покупки. Исключение Alipay подходит только при оплате через учитываемый банк; расходы с отдельного баланса Alipay эта конфигурация пропустит.

Курсы берутся из Frankfurter и кешируются на сутки. Итоги в HKD оценочные, пересчитываются по доступному курсу; это не банковская выписка. Звёздочка обозначает потенциально неполные данные.

### Передача данных из Shortcuts

Scriptable получает данные через параметр действия **Run Script**, а не читает уведомления самостоятельно. [Документация Scriptable](https://docs.scriptable.app/args/) описывает `shortcutParameter`.

Для проверки создай команду:

1. Добавь **Dictionary** с полями `source` = `Octopus` и `message` = `HK$10.00 for Train`.
2. Добавь действие **Run Script** от Scriptable, выбери `SpendWidget`, передай словарь в Parameter. Не включай Show When Run, если нужен запуск без меню.
3. Добавь **Show Result** для результата скрипта. Ожидаемый ответ: `Записано: 10 HKD · Train`. Этот запуск сохраняет тестовый расход. После проверки исключи его через журнал.

Принимается также текст, где первая строка содержит источник:

```text
Mox
You spent HKD 25.50 at Example Cafe
```

Для проверки без сохранения используй встроенное меню **Тест уведомления**. Вымышленный пример Octopus должен дать `10 HKD`, `Train`, категорию `Транспорт`.

На iOS 27 есть триггер уведомления от выбранного приложения: [Apple, WWDC26](https://developer.apple.com/videos/play/wwdc2026/310/). Создай автоматизацию получения уведомления Mox или Octopus и передай имя приложения в `source`, а доступные заголовок и текст в `title` и `message`. При необходимости получи эти свойства из входного уведомления перед созданием словаря. Меню и доступность полей зависят от версии iOS; сначала проверь передачу вымышленного текста обычной командой. [Инструкция Apple по автоматизациям](https://support.apple.com/en-euro/guide/shortcuts/apdfbdbd7123/10.0/ios/27).

Если триггера уведомления в твоей версии iOS нет, используй ручной ввод, копирование текста в команду или передачу текста через меню «Поделиться». Триггер Apple Pay Transaction сам по себе не подходит: парсер ждёт поддержанный текст Mox/Octopus, а не произвольный объект транзакции.

### Данные и обновление

История хранится локально через `FileManager.local()` в `SpendWidget-data-v1`. В ней остаются суммы, магазины и исходные тексты уведомлений. Экспорт JSON содержит эти данные.

Перед обновлением сохрани старый код и экспорт истории в личном месте. Затем замени только код скрипта, оставив имя `SpendWidget`. Папку `SpendWidget-data-v1` не удаляй. Поддерживается прежняя история с форматом событий `schema: 1`; импорт произвольных старых форматов не реализован.

## QuickActions и шесть команд

Создай команды с точными именами из таблицы. Виджет запускает их через [URL-схему Shortcuts](https://support.apple.com/en-euro/guide/shortcuts/apd624386f42/ios); переход в приложение «Команды» возможен.

| Кнопка | Имя команды | Настройка |
|---|---|---|
| Happ VPN | `QA VPN` | Set VPN → выбери свой профиль Happ → Connect или Toggle |
| Идея | `QA Idea` | Ask for Input → Copy to Clipboard → URL своей страницы Notion → Open URLs |
| TrainChinese | `QA Translate` | Open App → TrainChinese |
| Таймер | `QA Timer` | Choose from Menu: 1 час / 3 часа → Start Timer на 3600 / 10800 секунд |
| Домой | `QA Home` | Маршрут от текущего местоположения до своего адреса; выбери Google Maps или Apple Maps и способ передвижения |
| Slack себе | `QA Slack` | Ask for Input → Copy to Clipboard → Open App → Slack; вставь текст и отправь в DM себе |

Для `QA Idea` укажи подсказку «Какая идея?», в Copy to Clipboard передай Provided Input. Ссылку страницы возьми в Notion через Share → Copy link. После открытия вставь текст самостоятельно; автоматическое создание записи через Notion API здесь не настроено.

Для `QA Slack` используй подсказку «Что отправить себе?». Если твоя версия Slack предоставляет собственное действие отправки сообщения в Shortcuts, можешь заменить копирование и открытие приложения этим действием, указав свой DM и Provided Input. Наличие такого действия здесь не подтверждено. Для отправки через Slack API потребуется отдельная личная настройка авторизации; токены в виджет не добавлены.

Домашний адрес, ссылку Notion и получателя Slack настрой только на своём телефоне. В репозитории их нет. Сначала проверь каждую команду кнопкой ▶ в Shortcuts, затем через виджет.

## Проверка исходников

Проверены синтаксис обоих скриптов и 17 групп проверок: Mox/Octopus, категории, суммы и даты, исключения, скрытие OTP, дубли, сохранение и правки, курсы и возвраты, шесть кнопок QuickActions и ссылки. Проверки используют имитацию API Scriptable и вымышленные данные. На реальном iPhone запуск, отображение, автоматизации и команды приложений ещё нужно проверить.

```sh
node tests/verify.cjs
```

Для публичной копии заменён пример реального уведомления на вымышленный и исправлена проверка обрезанного названия магазина. Подробности в [CHANGELOG.md](CHANGELOG.md).

## Что не публиковать

В репозитории только код, инструкции и проверки. Не добавляй историю расходов, экспорт, личные настройки команд, снимки уведомлений, адреса, номера карт, Slack/Notion/VPN-токены. `.gitignore` исключает типичные файлы с такими данными, но перед публикацией своих изменений проверяй содержимое вручную.
